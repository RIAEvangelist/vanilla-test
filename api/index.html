API reference

A small stateful runner with explicit completion.

Each instance owns its active test, descriptions, results, and type helper. A reported runner is final and returns the same frozen snapshot on every later report.

Imports and lifecycle

import VanillaTest, {
    VanillaTest as NamedVanillaTest,
    VANILLA_TEST_COMPLETE_EVENT
} from 'vanilla-test';

The default and named class exports are the same value. VanillaTest extends EventTarget; completion uses the exported vanilla-test:complete event name.

Runner methods

new VanillaTest()

Creates an isolated runner. Instances do not share descriptions, strict state, listeners, or results.

Returns
A new VanillaTest instance.

test.expects(description)

Starts one test and logs its numbered description. The raw description must be a unique string within this runner.

Returns
The numbered test description.
Throws
TypeError for a non-string; ReferenceError for an active test, duplicate description, or reported runner.

test.pass(strict = false)

Records the active test as passed. A repeated decision returns the existing description unless this call's strict argument is true.

Returns
The active numbered description.
Throws
TypeError for a non-boolean argument; ReferenceError when no test is active or a strict repeated decision occurs.

test.fail(strict = false)

Records the active test as failed. Repeated-decision behavior matches pass().

Returns
The active numbered description.
Throws
The same argument, active-test, and strict-repeat errors as pass().

test.done()

Finishes the active test. If neither decision method ran, done() records the test as failed before clearing it.

Returns
The finished numbered description.
Throws
ReferenceError when there is no active test.

test.report()

Prints the report once, freezes the result and its arrays, schedules the completion event in a microtask, and returns the result. An empty suite is a successful report.

Returns
The same frozen result object for every call.
Throws
ReferenceError if an active test has not been finished.

test.onComplete(listener, options)

Subscribes to the completion event and returns an idempotent unsubscribe function. The frozen result is available at event.detail.

Returns
A zero-argument unsubscribe function.
Throws
TypeError when listener is not a function.

test.delay(iterations = 1000)

Runs a synchronous loop and returns the runner for chaining. It is retained as a small host-neutral delay primitive, not an asynchronous timer.

Returns
The runner instance.
Throws
TypeError unless the value is a nonnegative safe integer.

Result contract

Consumers should branch on ok or failureCount, not parse the rendered console string.

{
    passed: ['1) .expects addition preserves the total'],
    failed: [],
    total: 1,
    failureCount: 0,
    ok: true,
    report: 'rendered console report'
}
  • The object and both arrays are frozen.
  • ok is true exactly when failureCount is zero.
  • report() never calls process.exit() or sets process.exitCode.
  • The completion event fires after report() returns, in a microtask, and only once.

Type helpers and strict state

Each runner owns one strong-type instance:

MemberBehavior
test.isThe complete strong-type instance for predicate and assertion helpers.
test.compareA direct reference to test.is.compare.
test.throwA direct reference to test.is.throw.
test.strictReads or writes the helper's boolean strict setting. This is separate from the per-call strict argument on pass() and fail().

Completion events

const unsubscribe = test.onComplete((event) => {
    console.log(event.detail.ok);
    unsubscribe();
}, { once: true });

const result = test.report();
// event dispatch occurs in the next microtask
Subscribe before reporting.

A runner dispatches completion once. Calling report() again returns the cached result but does not log or dispatch again.

Core invariants
  • One active test at a time
  • Unique descriptions per runner
  • Undecided means failed
  • Reported means sealed
  • Results are deeply immutable

See the test strategy for the checks that enforce these behaviors.
